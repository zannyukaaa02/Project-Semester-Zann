Selamat Datang di Modul HTML

Selamat datang! Modul ini membantu kamu mempelajari dasar-dasar HTML melalui materi singkat dan contoh kode.

Tips belajar: baca penjelasan, perhatikan contoh, lalu coba tulis ulang kodenya di editor.

Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk menyusun struktur dan konten halaman web, seperti judul, paragraf, gambar, tautan, tabel, dan formulir.

Peralatan yang dibutuhkan

  • Editor kode, misalnya VS Code atau Geany.
  • Browser, misalnya Firefox.
  • Folder project untuk menyimpan file HTML dan CSS.

Contoh dokumen HTML sederhana

KODE HTML

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Halaman Pertamaku</title>
</head>
<body>
  <h1>Halo, dunia!</h1>
  <p>Ini website pertamaku.</p>
</body>
</html>
